# MMK Grup – Angular Frontend

Kurulum ve çalıştırma:

    npm install
    npm start          # http://localhost:4200
    npm run build      # dist/mmk-grup/browser

İçerik düzenleme:
- Ürünler: src/app/data/products.ts
- Firma bilgileri, SSS, teknik katmanlar: src/app/data/site.ts
- Görseller: public/assets/ (doors = kapılar, scenes = ortam görselleri)
